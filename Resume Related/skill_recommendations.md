- **Why**: In Go-based microservice architectures (like your EFS project), inter-service communication typically uses gRPC for high performance and low serialization overhead compared to JSON REST.

- **Why**: You mentioned using Redis, RabbitMQ, Kafka, and API Gateway. Explicitly naming concepts like **Distributed Locks (Redlock)**, **Token Bucket Rate Limiting**, and **Idempotency** shows high engineering maturity beyond a 1-year developer.

- **Why**: Enterprise NestJS/Next.js/Go apps use ORMs or query builders for type-safe database queries.
- **Where to put it**: In *Backend / Tools*.

### 🟢 7. NGINX & Reverse Proxy / API Gateway
- **Why**: Goes hand-in-hand with Docker and Microservices for load balancing, SSL termination, and API routing.
- **Where to put it**: In *DevOps & Cloud*.

### 🟢 8. CI/CD (GitHub Actions)
