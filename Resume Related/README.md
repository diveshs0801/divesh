## 🚀 How to Export to PDF

1. Open [resume.html](file:///C:/Users/Admin/.gemini/antigravity-ide/scratch/divesh/resume.html) in Google Chrome or any modern browser.
2. Press `Ctrl + P` (or `Cmd + P` on Mac).
3. Set **Destination** to `Save as PDF`.
4. Set **Margins** to `None` or `Default` (the built-in `@page` CSS takes care of margins).
5. Uncheck **Headers and footers** and ensure **Background graphics** is checked.
6. Click **Save**!
